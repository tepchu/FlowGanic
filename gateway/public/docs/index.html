FlowGanic API

Koordinasi distribusi sampah Kota Bandung, kelompok kononkatanya. Wilayah pilot RW 05 Lebak Siliwangi, Kecamatan Coblong. Base URL https://kononkatanya.stei.fun/api.

Semua endpoint kecuali /health memerlukan header X-API-Key. Tekan Authorize di bawah, masukkan kunci dari kelompok, lalu pakai Try it out pada endpoint mana pun.

Kelompok mitra memakai /wilayah, /pengolah, dan /rekap. /rekap hanya mengembalikan agregat anonim: akun, alamat, dan riwayat permintaan warga tidak pernah dibuka.

Data wilayah, pengolah, dan kapasitas masih data contoh untuk menguji alur koordinasi, bukan data operasional. Setiap respons memuat label sumber.
