FlowGanic API

Layanan mobilitas multimoda Jakarta, kelompok kononkatanya. Base URL https://kononkatanya.stei.fun/api.

Semua endpoint kecuali /health memerlukan header X-API-Key. Tekan Authorize di bawah, masukkan kunci dari kelompok, lalu pakai Try it out pada endpoint mana pun.

Data halte, ruas, dan jadwal masih data contoh, bukan feed operator dan bukan hasil model AI. Setiap respons memuat label sumber atau metode.
